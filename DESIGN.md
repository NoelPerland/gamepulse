# GamePulse design

- Role: inspect game telemetry, progression and remote settings. Demo sessions are fictional and labeled.
- Voice: operator language. Show what a measure means and what data is available; avoid marketing filler.
- Type: compact system UI for tables and controls, monospace for event IDs, keys and measurements.
- Color: charcoal console, pale text and restrained signal green. Contrast comes before atmosphere.
- Layout: live data and useful filters lead. Preserve table density and distinguish demo from keyed ingestion.
- Motion: immediate state feedback only; no floating dashboards or decorative charts.
